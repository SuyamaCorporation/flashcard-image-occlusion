# Image Occlusion Flashcard Maker

Upload any image, draw red boxes to cover regions, then test yourself by revealing the hidden areas one by one.

## Features
- Upload any image (anatomy diagrams, maps, charts) — stored locally as a data URL, no server needed
- Edit Mode: click-drag to draw occlusion boxes; each box can have an optional text label; delete individual boxes
- Test Mode: boxes shown as opaque red; click any box or press Enter to reveal the next one sequentially
- Hint button reveals one box at a time; Reveal All and Reset controls for full test management
- Progress bar tracking how many boxes have been revealed; save and load named occlusion sets to localStorage

## Usage
Click Upload Image and select a file. In Edit Mode, click and drag to draw red boxes over regions you want to memorize. Optionally type a label and click Add Box. Switch to Test Mode and try to recall what is hidden before clicking each box to reveal it. Press Enter to reveal boxes in order. Save your set with a name to reload it in future sessions.
